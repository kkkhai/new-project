# Audio

Drop sound files here and they are picked up automatically at build time; no code changes needed.
Until a file exists, the game plays a short built-in placeholder beep for that sound.

Allowed licences: CC0, Pixabay License, Sonniss GDC bundle. Add every file to `CREDITS.md`.

## Sound effects: `sfx/<name>.ogg` (or `.mp3` / `.wav`)

| Name | Plays when | Suggested source |
| --- | --- | --- |
| `step` | (reserved) footstep | Kenney RPG Audio |
| `dig` | digging dirt | Kenney RPG Audio |
| `diamond` | picking up a diamond | Kenney RPG Audio (coin) |
| `red` | picking up a red diamond | Kenney Interface Sounds |
| `item` | key, heart or tool pickup | Kenney RPG Audio |
| `push` | pushing a boulder | Kenney Impact Sounds |
| `land` | a boulder lands, fills a pit, breaks a wall | Kenney Impact Sounds |
| `crush` | the player is crushed | Kenney Impact Sounds |
| `hurt` | spikes, pits, bites | Kenney RPG Audio |
| `checkpoint` | checkpoint saved | Kenney Interface Sounds |
| `door` | door unlocked | Kenney RPG Audio (creak) |
| `gate` | gate opens/closes, lever | Kenney Impact Sounds |
| `cut` | machete cuts vines/thorns | Pixabay |
| `splash` | boulder drops into the river | Pixabay |
| `enemy` | enemy crushed | Kenney Impact Sounds |
| `steal` | monkey steals a diamond | Pixabay |
| `boss` | boss hit / defeated | Sonniss bundle |
| `exit` | exit gate opens | Kenney Interface Sounds |
| `win` | level complete | Kenney Interface Sounds |
| `click` | menu button | Kenney Interface Sounds |

## Music: `music/<name>.ogg` (or `.mp3`), loops while playing

| Name | Plays in | Suggested source |
| --- | --- | --- |
| `jungle` | Jungle levels | TAD – Unexplored (looping), CC0 |
| `desert` | Desert levels | Tom Feldmann – Wild Music Pack (desert), CC0 |
| `snow` | Snow levels | Tom Feldmann – Wild Music Pack (snow) or Bobjt – Snow Globe, CC0 |
| `boss` | Boss stages | Tom Feldmann – Wild Music Pack (boss), CC0 |
